# bleood.online clone

A high-fidelity recreation of [bleood.online](https://bleood.online/)
built with Next.js 15, React 19, TypeScript, Vanilla CSS, and Three.js. 
Includes the full interactive clearing with a real-time 3D figure, dynamic
lighting mask, CRT retro minigames, vintage cassette music player, art gallery
with lightbox, tour dates, handwritten notes, and help policy pages.

Part of the **cloned-websites** collection.

---

## Getting Started

### Prerequisites

- Node.js 18.18+ or 20+
- npm

### Installation

1. Navigate to this folder:
   ```bash
   cd "bleood.online clone"
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

5. Production Build (optional):
   ```bash
   npm run build
   npm run start
   ```
